## Descarga

**[BatteryHub.exe](https://github.com/Maurito2004/BatteryHub/releases/download/v1.2.0/BatteryHub.exe)** — un solo archivo, sin instalar, sin permisos de administrador. Descargalo, ejecutalo y activá *Configuración → Iniciar con Windows*.

> Probado en Windows 11. Windows 10 todavía sin verificar.

## Novedades en 1.2.0

- **Actualizaciones desde la app.** Abajo de todo del menú (clic en el widget) aparece el estado:
  - **"App actualizada (BatteryHub 1.2.0)"** si tenés la última versión. Un clic vuelve a buscar.
  - **"Actualizar a la versión X"** cuando sale una nueva. Un clic la descarga desde este Release, reemplaza el `.exe` y BatteryHub **se reinicia solo** con la versión nueva (el orden, los alias y la configuración se mantienen).
  - Si algo falla (sin internet, carpeta protegida), ofrece abrir esta página para bajarla a mano.
- La búsqueda es automática: 30 s después de iniciar y una vez por día, sin molestar. Solo consulta la API pública de GitHub; no envía ningún dato tuyo.
- `BatteryHub.exe --update` hace lo mismo desde la consola.

**Importante:** el botón de actualizar existe a partir de esta versión. Si tenés la 1.1.x o anterior, bajá la 1.2.0 a mano una vez; de acá en adelante se actualiza sola.
