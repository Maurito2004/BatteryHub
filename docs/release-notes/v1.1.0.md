## Descarga

**[BatteryHub.exe](https://github.com/Maurito2004/BatteryHub/releases/download/v1.1.0/BatteryHub.exe)** — un solo archivo, sin instalar, sin permisos de administrador. Descargalo, ejecutalo y activá *Configuración → Iniciar con Windows*.

También está el `.zip` portable (exe + README).

> Probado en Windows 11. Windows 10 todavía sin verificar.

## Novedades en 1.1.0

- **Reordenar arrastrando:** mantené apretado un dispositivo del widget de la barra y movelo a otro lugar. El orden se guarda.
- **Menú oscuro / claro con íconos**, al estilo de los menús modernos de Windows 11. *Configuración → Tema del menú*: igual que Windows, oscuro o claro.
- El menú muestra los dispositivos en el mismo orden que la barra, con el ícono de cada uno, y la versión de la app.
- **Modo juego:** una ventana maximizada normal ya no cuenta como juego (barra autoocultable, TranslucentTB).
- Releases automáticos: cada versión se compila en GitHub y publica el `.exe` acá.

## Dispositivos verificados

Mouse ATK / VXE (Compx), teclado AULA F75, DualSense (Bluetooth y cable), GameSir Cyclone 2 (cable). Ver el README para la lista completa.
