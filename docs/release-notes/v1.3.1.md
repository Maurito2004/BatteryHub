## BatteryHub 1.3.1

### Podés apagar la búsqueda automática de actualizaciones
Nuevo interruptor en **Configuración… → General → Buscar actualizaciones automáticamente**. Viene
prendido, como hasta ahora: revisa GitHub 30 segundos después de arrancar y una vez por día, y solo
envía la versión de BatteryHub. Si lo apagás, no se conecta a internet salvo que toques
**Buscar actualizaciones**.

### Política de firma y privacidad
El README tiene una sección **Code signing policy** (requisito de SignPath Foundation para firmar el exe
gratis). Ahí está:
- quién escribe, revisa y aprueba cada versión;
- todas las conexiones que hace la app y qué envía;
- qué cambia en tu sistema;
- cómo desinstalarla.

Cada release la enlaza al pie.

**Actualizar:** desde la app (abajo de todo del menú) o bajando el nuevo `BatteryHub.exe`.
